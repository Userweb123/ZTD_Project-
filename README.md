# ZTD Project

Для почаку 
людей - 4 
платформа - Unity
проєкт - ігра 
платформа - веб 
тип - тайкон + ТАВЕР ДЕФЕНС + АВТОМАТИЗАЦІЯ  
Технійчний Опис ігри:
Світ 3d + 2d інтерфейс 
Основна механіка клікер/майнер + тайкон стиль(покращення і тд)

1. Спавн гравця

Гравець одразу з’являється біля своєї хати.

Немає вступів.
Немає катсцен.
Немає пояснень сюжету.

Просто:

туман

тиша

покинуті будинки навколо

атмосфера занепаду

2. Його дім = БАЗА

Це єдина точка безпеки.

База має:

склад ресурсів

кілька початкових будівель

1–2 прості турелі

генератор енергії

просту шахту для ресурсів

Фактично:

Хата = головний хаб гравця

3. Що гравець бачить одразу

На старті:

будинок (його база)

навколо кілька закинутих споруд

кілька ресурсів на землі (метал, деталі)

Немає примусових підказок.
Лише мінімальні написи типу:

Move

Interact

Open Base

4. Перша логіка гри (інтуїтивна)

Гравець швидко розуміє:

тут моя база

тут можна щось покращувати

тут я у безпеці

зовні — небезпека

5. БАЗА — прості дії

Гравець може:

зібрати ресурси

покращити будівлю

побудувати нову турель

прокачати видобуток

Ніяких діалогів.
Ніяких NPC.
Тільки механіка.

6. Вороги

Через короткий час:

приходять вороги

атакують базу

турелі автоматично стріляють

Гравець розуміє:

Треба качати базу, інакше її зламають

7. Основний цикл гри

Дуже простий:

База добуває ресурси

Гравець підбирає лут навколо

Покращує базу

Стає сильнішим

Вороги стають сильнішими

Повтор

8. Дослідження (опціонально)

Якщо гравець виходить далі:

знаходить будівлі

лутає

приносить ресурси назад на базу

Без історій.
Без квестів.
Тільки геймплей.

9. Суть концепту в одному реченні

Ти спавнишся біля своєї хати. Це твоя база. Захищай її, автоматизуй ресурси, розширюй контроль над світом.
